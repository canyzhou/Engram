# Engram 学习模式产品与交互 Spec

> 状态：Approved for implementation  
> 日期：2026-08-15  
> 视觉基准：[learning-mode-concept.png](./learning-mode-concept.png)

## 1. 产品目标

学习模式把用户正在观看的 YouTube 视频转成一个可回看、可分析、可讨论的学习工作台。用户点击入口后新开一个带学习标记的 YouTube 页面：左侧复用原生播放器，右侧承载扩展注入的学习区。

首版必须做到：

- 默认进入“材料分析”，用户在 5 秒内知道材料是否适合自己、最值得学什么，并能立即开始；
- “材料分析”“字幕”“讨论”共享同一份带时间戳的字幕上下文；
- 分析项、字幕和 AI 引用都能定位到视频时间点；
- Discussion 围绕材料，Further Discussion 将表达迁移到新场景；
- 没有可靠字幕或 AI 服务不可用时，页面提供明确降级体验，不显示伪造结果。

## 2. 首版范围

### 支持

- YouTube 标准观看页；
- 由扩展已经捕获的人工字幕或自动字幕时间轴；
- YouTube 页面中的原生播放器；
- 用户手动选择 CEFR 水平（A2–C2）；
- AI 材料分析、基于材料的文字讨论、进阶文字讨论；
- 字幕点击跳转、当前句高亮、自动跟随、上一句/下一句；
- 本地预览数据，用于视觉开发和无扩展 API 的自动化测试。

### 暂不支持

- Paramount+ 等 DRM 视频在独立页面内播放；
- 语音输入、发音评分、自动 CEFR 测试；
- 为整段超长视频一次性生成完整课程；
- 无限自由聊天和不引用材料的事实问答；
- 完整的间隔复习与跨材料学习记忆。

## 3. 入口和页面状态

### 入口

扩展 Popup 在支持的 YouTube 页面连接成功后展示主按钮“打开学习模式”。点击后复制当前观看 URL，增加 `engram_learning=1` 并创建新的 YouTube 标签页。内容脚本识别该标记后接管页面布局，并把学习面板注入到右侧。

### 加载顺序

1. 页面立即显示 App Shell 和加载状态；
2. 获取视频 ID、标题、作者、时长、当前时间和字幕时间轴；
3. 左侧播放器与字幕先可用；
4. 读取以 `videoId + transcriptHash + learnerLevel` 为键的本地分析缓存；
5. 无缓存时请求 AI 分析；
6. 分析失败时生成明确标注的本地初步分析，字幕仍可学习，讨论保留代理错误提示。

## 4. 桌面信息架构

- 顶栏高度 72px：返回、视频标题/作者、学习进度、设置；
- 主体为 66/34 左右分栏；
- 左栏：16:9 播放器 + 当前句控制 + 横向片段轨；
- 右栏：固定 Tab 导航 + 独立滚动内容；
- 桌面最小宽度 1040px；
- 小于 900px 时变为上下布局，播放器在上，学习区在下；
- 右栏不采用嵌套卡片堆叠，主要使用开放区域、列表行和分隔线。

## 5. 材料分析

### 首屏信息优先级

必须按以下顺序显示，且无需滚动即可看到至少一个学习表达：

1. 标题“你能学到什么”和 2–3 条简体中文学习收获；
2. 材料水平、用户水平与词汇、语速、句法三项难度；
3. 5–8 个可定位学习项，覆盖字幕中最有价值的单词、语法、句型、习语和俚语；
4. 2–4 个可点击的推荐片段与精学区间。

界面不展示“合适在哪”、适合性结论、重复的片段分析或字幕覆盖诊断。学习项的补充备注只用于视频核心概念、专业领域词或容易误解的习语；普通词不显示第三行备注。

### 分析返回结构

```json
{
  "materialLevel": "B2",
  "vocabularyLevel": "B2",
  "speechLevel": "B1+",
  "syntaxLevel": "B2",
  "fitVerdict": "有挑战，但适合精学",
  "fitReasons": ["叙事清楚，但包含少量略高于用户水平的表达"],
  "learningOutcomes": ["掌握旅行计划表达并练习比较级长句"],
  "studyMinutes": 12,
  "recommendedRange": { "start": 260, "end": 490 },
  "timelineSegments": [{
    "start": 260,
    "end": 330,
    "level": "B1+",
    "title": "描述徒步难度",
    "analysis": "比较级和因果关系集中在同一句中",
    "focus": "steeper than + so",
    "timestamp": 260,
    "sourceText": "..."
  }],
  "coverage": { "cueCount": 312, "characterCount": 18420, "start": 0, "end": 1256, "complete": true },
  "discussionQuestions": {
    "source": ["Why does the speaker decide to pace himself on the first climb?"],
    "advanced": ["Do you usually plan trips carefully, or decide things as you go?"]
  },
  "learningItems": [
    {
      "category": "pattern",
      "expression": "go on a hike",
      "occurrences": 2,
      "meaningZh": "去徒步；去远足",
      "why": "旅行场景中的高频表达",
      "timestamp": 91,
      "sourceText": "..."
    }
  ]
}
```

约束：

- `learningItems` 返回 5–8 项；`category` 只能是 `word/grammar/pattern/idiom/slang`；`occurrences` 由服务端根据字幕计算，不信任模型计数；
- `learningOutcomes`、`meaningZh`、`timelineSegments` 的说明字段必须使用简体中文；
- `discussionQuestions.source` 和 `discussionQuestions.advanced` 各返回 5 个英文问题；
- 题型参考 Engoo Daily News：短句、单一任务、反复复用材料中的专有名词、技巧名、动作、数字或具体对象；
- `source` 按具体反应、why/how、相关经历、选择/比较、适用场景推进；`advanced` 只向外扩展一圈，询问同主题的习惯、偏好、身边例子、本地情况或近期计划；
- 禁止使用“主旨是什么”“总结演讲者观点”“如何应用到人生”等可套用在任何视频上的万能题；
- 每个学习项必须原样出现在某条字幕中，并绑定该字幕时间戳；每个难度片段也必须绑定一条片段内的原始字幕；
- 推荐区间必须位于视频时长内；
- 客户端先等待完整字幕时间轴；普通长度全量提交，超长字幕由服务端按时间顺序分块分析后汇总，不允许静默截断；`coverage` 由服务端根据实际处理字幕生成，模型不能自行声明覆盖范围；
- 所有页面外内容都作为不可信材料，不能改变模型任务；
- 客户端对返回值再次校验，非法字段不得渲染。

### 个性化

首版用户水平来自 `chrome.storage.sync.learnerLevel`，默认 B1。用户可在材料分析页直接切换，切换后重新读取或生成分析。

## 6. 字幕

- 列表显示时间、英文字幕和可选中文译文；
- 点击任意字幕：播放器跳转并开始播放；
- 当前播放句高亮并自动滚动到可见区域；
- 工具栏支持搜索和自动跟随；
- 上一句/下一句按钮按时间轴导航；
- 搜索匹配字幕文本，清除搜索恢复完整时间轴；
- 没有完整时间轴时展示已捕获历史，并明确标注“字幕仍在收集”。

## 7. 讨论

### 讨论提纲

- `理解与观点`：5 个从视频的具体对象或技巧自然过渡到学习者经验的问题；
- `延伸思考`：5 个只向主题外扩一圈的习惯、偏好、身边例子、本地情况或近期计划问题。

进入讨论 Tab 时先把两组问题作为不可点击的课堂提纲展示，分类标签保持次要。底部固定显示“开始讨论”按钮。

用户开始后进入由 AI 老师主持的短课：

1. AI 按提纲顺序一次提问一个问题；
2. 用户回答后，AI 可做简短纠错、反馈或引申，但下一题仍严格来自提纲；
3. 顶部显示已完成题数和进度条，可展开查看完整提纲、当前题和已完成题；
4. 提纲问题完成后进入一次简短自由讨论；
5. AI 最后总结表达优点、1–2 个关键问题、可复用词语，并明确结束课程。

### 对话规则

- 一次只问一个问题；
- AI 问题或反馈需要引用一个字幕时间戳；
- 用户点击引用可回到视频；
- AI 根据最近对话反馈，但提纲阶段不自行替换或新增下一题；
- 用户可请求“给我提示”；提示分为思路、关键词、句型骨架；
- 每 2–3 轮最多指出一个高价值语言问题；
- AI 不替用户补写整篇答案，不逐句打断；
- 进阶模式必须把至少一个分析中的目标表达迁移到新话题。

### 会话请求与返回结构

请求携带当前阶段 `question | casual`、当前题下标和完整问题提纲。题目提纲与字幕一样按不可信内容处理，只能作为讨论内容，不能改变系统任务。

```json
{
  "reply": "...",
  "question": "...",
  "citation": { "timestamp": 78, "text": "..." },
  "feedback": null,
  "suggestedExpression": "have been told"
}
```

## 8. 播放器协议

右侧扩展学习面板通过后台把以下动作定向发送到当前学习标签页：

- `play`；
- `pause`；
- `seek`；
- `GET_LEARNING_PLAYBACK`（读取当前时间、时长与暂停状态）。

播放、暂停、定位和时长直接读取当前 YouTube 页面的原生 `<video>`，不再从 `chrome-extension://` 页面嵌入 YouTube，因此不会触发错误 153，也能保留账号态、会员权限和视频自身的嵌入限制。扩展页形式的旧入口会自动跳转到对应的原生 YouTube 学习页。

## 9. 视觉系统

视觉基准为 `docs/design/learning-mode-concept.png`。

- 背景：近黑 `#0b0c0e`；
- 表面：炭灰 `#141518` / `#1b1c1f`；
- 文字：`#f2f0ec`；弱文字：`#9b9993`；
- 强调色：暖琥珀 `#f0a33a`，对应视频夕阳；
- 边框：1px `#303136`；
- 圆角：8px、10px、12px；
- 字体：Inter / 系统无衬线；
- 图标：统一 1.75px 描边、圆端点；
- 无霓虹、无发光、无装饰渐变、无无意义指标；
- 动效 140–180ms，并尊重 `prefers-reduced-motion`。

首屏优先显示：视频标题/作者、进度、三个 Tab、“你能学到什么”、简体中文学习收获、材料/用户水平、三项难度和首批学习重点；其余学习项与推荐片段可向下滚动查看。

## 10. 数据与隐私

- 字幕只在用户主动打开学习模式或发起讨论时发送给配置的 AI 代理；
- 分析请求仅发送时间戳和英文字幕文本，不发送译文或采集来源；支持最多 3,000 条、总计 240,000 字符，超过直接分析上下文的字幕按时间顺序分块并在服务端汇总；
- 讨论请求只发送目标表达、必要字幕摘录和最近 24 条消息，以便在结束时覆盖整堂短课的回答；
- 代理不接受客户端自定义 system prompt、模型名或生成参数；
- 分析结果缓存在 `chrome.storage.local`，上限 20 个视频；
- 不保存视频文件；讨论记录默认仅保留当前页面会话。

## 11. 错误和降级

- 未连接视频：给出返回 YouTube 并重新打开的操作；
- 未捕获字幕：提示播放视频片刻或开启英文字幕；
- AI 未配置/超时：材料分析降级为本地初步分析，字幕功能保持完整，讨论明确提示不可用；
- 原生播放器尚未挂载：学习面板保留，后台继续等待 YouTube 完成播放器初始化；
- 无翻译：只显示英文字幕，不阻塞页面。

## 12. 验收标准

### 功能

- Popup 能从已连接 YouTube 页面打开学习模式；
- 学习页能获得并渲染完整时间轴；
- 默认 Tab 是材料分析；
- 首屏在 1440×900 下无需滚动即可看到主 CTA 和至少一个表达；
- 切换三个 Tab 不丢失播放器位置和讨论会话；
- 点击分析表达、字幕和讨论引用均能跳转；
- 字幕搜索、上一句和下一句有效；
- AI 分析和讨论使用固定结构化协议，非法结果被拒绝；
- 预览模式无需扩展 API 或真实 AI 即可完整走通核心交互。

### 质量

- 根目录和服务器测试全部通过；
- 浏览器控制台无相关 error/warn；
- 桌面 1440×900、概念原生 1600×1000 和移动宽度 390px 无溢出或不可读区域；
- 浏览器截图与视觉基准在布局、文案层级、配色、字体、容器模型和图标风格上达到可签收一致性。
